Landslide Susceptibility

Susceptibility indicates where landslides are more likely; it is not a detection of an active event. Map language uses “potential landslide-prone region”.

Rainfall note: native IMD rainfall resolution is ~0.25° (~25 km); the 30 m grid interpolates the coarse field, it does not create 30 m accuracy.
